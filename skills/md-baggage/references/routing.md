# 轻量阶段建议

需要判断阶段或独立任务收尾时读取。结合项目的目标、状态和授权判断前置条件，不复写完整技能目录。

先判断当前工作是否完成；关键问题未决时继续当前阶段，前置缺失时建议补齐，不机械向后跳转。

下列只是候选：推荐前读取目标 Skill 的实际 SKILL.md，核对可用性、输入、调用方式及项目约定。

| 当前情况 | 候选下一步 |
| --- | --- |
| 单需求规则／验收待讨论 | grill-with-docs 或可用同类能力 |
| 已达成共同理解，需要固化规格 | to-spec |
| 规格明确，实施需拆分任务 | to-tickets |
| 任务边界、依赖、验收与实施授权齐备 | implement 或用户指定实施能力 |
| 本次实现具备审查材料 | code-review，遵循最终模型约定 |
| 一轮交付需改进环境或规范 | retro |

用户直接使用某技能时，围绕其阶段准备／维护即可。测试驱动方法、具体架构和数据库设计交给相应能力；巨大模糊目标先明确探索需要，不在此展开全项目规划。

给当前最有用的一个建议，确有分支再给备选，说明理由和必要输入。目标缺失或工具不支持调用时，说明可用替代或给调用建议，不宣称已执行，也不自动安装技能。

建议不扩大实施、提交、合并或发布授权。项目 AGENTS 保留简版流程和文件规则，专项正文各有来源，不为每阶段另建状态文件。
