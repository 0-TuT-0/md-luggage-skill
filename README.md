# md-baggage

用于 AI 协作开发的文档管理 Skill。当前版本 0.1.1，使用一个短入口，内部包含文档管理内核和轻量阶段建议；接入、记录、测试与审核细则按需读取。

## 使用

源码入口：[skills/md-baggage/SKILL.md](skills/md-baggage/SKILL.md)。支持本地路径引用的环境可先按路径试用；完成验证与最终审核后再安装到工具支持的用户级 Skill 目录。

示例请求：

- “使用 $md-baggage 为报名需求准备 grill 所需资料。”
- “同步刚确认的规则，保留尚未实现的状态。”
- “盘点旧资料，先给整理方案。”
- “核对本次文档引用，并说明当前阶段缺口。”

安装包为 skills/md-baggage/ 整个目录。自动选择保持开启；实际触发依赖工具的发现机制，不是后台监听，也不保证每轮都触发。

## 结构与范围

- SKILL.md：目的、触发和共同约定。
- references/：按本次文档动作读取的专项规则。
- assets/：项目 AGENTS、共享入口、需求入口和测试模板。

项目事实留在项目根 AGENTS 和 docs/share/，个人过程留 docs/private/；本仓库不打包业务项目、聊天原文或凭据。

首版支持接入、需求准备、已确认变化同步、相关资料检查及阶段建议。实现、测试执行和最终审核复用既有能力。大目标分解、完成度审计、数据库设计及后台调度不作为首版能力。

源码通过 Git 迭代，仓库为 [0-TuT-0/md-luggage-skill](https://github.com/0-TuT-0/md-luggage-skill)。当前未全局安装。最终审阅模型由用户指定，普通校验和行为试用不替代最终审核。
