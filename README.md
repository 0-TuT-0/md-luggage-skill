# md-baggage

用于 AI 协作开发的文档管理 Skill。v0.1 使用一个短入口，内部包含文档管理内核和轻量阶段建议；接入、记录、测试与审核细则按需读取。

## 使用

源码入口：[skills/md-baggage/SKILL.md](skills/md-baggage/SKILL.md)。支持本地路径引用的环境可先按路径试用；完成验证与最终审核后再安装到工具支持的用户级 Skill 目录。

示例请求：

- “使用 $md-baggage 为报名需求准备 grill 所需资料。”
- “同步刚确认的规则，保留尚未实现的状态。”
- “盘点旧资料，先给整理方案。”
- “核对本次文档引用，并说明当前阶段缺口。”

安装包为 skills/md-baggage/ 整个目录。自动选择保持开启；实际触发依赖工具的发现机制，不是后台监听，也不保证每轮都触发。

## 结构与范围

- SKILL.md：目的、触发和共同约定。
- references/：按本次文档动作读取的专项规则。
- assets/：项目 AGENTS、共享入口、需求入口和测试模板。

项目事实留在项目根 AGENTS 和 docs/share/，个人过程留 docs/private/；本仓库不打包业务项目、聊天原文或凭据。

首版支持接入、需求准备、已确认变化同步、相关资料检查及阶段建议。实现、测试执行和最终审核复用既有能力。大目标分解、完成度审计、数据库设计及后台调度不作为首版能力。

源码通过本地 Git 迭代；当前未全局安装，远程同步暂缓。最终审阅模型由用户指定，普通校验和行为试用不替代最终审核。

## v0.1 验证摘要

2026-10-27，对本次 v0.1 源码工作区完成包结构、命名与元数据校验，相对引用及未完成脚手架检查通过。入口为 46 行，专项资料按分支读取。

独立代理在隔离的临时 Git 项目中按本 Skill 实际处理以下请求，核对输出及文件差异：

| 场景 | 观察结果 |
| --- | --- |
| 新项目建立资料入口 | 仅生成有效入口与忽略规则，保留未知项；生成链接及 private 忽略状态核对通过 |
| 无 spec 的单需求准备 | 读需求与身份依赖，未读无关需求或个人历史；没有强制先写规格 |
| 已确认新规则但未实现 | 更新规格、主要进度和验证摘要，保留待实现／未验证；测试文件与代码未改 |
| 旧资料迁移盘点 | 指出完整目标路径冲突、仅本地规则和已跟踪个人资料；未移动或覆盖文件 |
| 既有旧入口下准备议题 | 复用旧导航开展讨论，不要求先迁移；未混用其他独立项目的决定 |

这些结果覆盖指令遵循与文档操作，未验证全局安装后的自动选择，也未运行真实业务测试。最终指定模型审核尚未进行。
